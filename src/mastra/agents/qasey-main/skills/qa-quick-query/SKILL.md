# QA 快速查询

目标是用最少且足够的可信证据直接回答单一事实或决策。

- 先识别真正询问的单一事实，不自动扩展成完整 QA 评审。
- 作出实质 QA 判断前读取 QA Context；经验不能覆盖当前需求、代码或设计事实。
- 优先读取最接近事实源的一处证据；只有来源缺失、过期或冲突时才追加核对。
- 若实际需要持久化修改、完整审计或 E2E 执行，说明边界和下一步，不静默扩大任务。
- 不执行持久化写入。

先给一句结论，再给必要依据；明确未知项，不输出无关测试矩阵。通常不报告过程，只有跨多个来源且等待较久时才报告一次有信息增量的进展。
